## Purpose
Builds a dated chronology of the case from every document in the file: the "list of dates and events" used in petitions and briefs.

## Steps
1. Go through each document in the case file index and pick out every dated event.
2. Put them in date order and remove duplicates.
3. Flag gaps, contradictions between documents, and limitation-sensitive dates.
4. Present the chronology as a table, then add a short synopsis.

## Instructions
- Use only dates found in the documents. Cite each row, like [Doc 2, p. 1].
- Table columns: Date | Event | Source.
- Under "## Result", give the table, then a five-line synopsis.
